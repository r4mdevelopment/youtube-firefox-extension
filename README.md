# YouTube MP4 Downloader

Firefox-first расширение для скачивания доступных видео YouTube в MP4. Работает внутри браузера: отдельное приложение и установленный FFmpeg не нужны.

**Chromium: 0.1.8. Подписанная Firefox-сборка: 0.1.7.** [Скачать сборки из Releases](https://github.com/r4mdevelopment/youtube-firefox-extension/releases/latest).

## Возможности

- Кнопка **«Скачать»** под видео, слева от лайков. Нажмите её и выберите качество.
- Реальный список совместимых MP4/H.264/AAC форматов: от 144p до 1080p, если они доступны у ролика.
- До **четырёх одновременных загрузок из разных вкладок**. В каждой вкладке доступна одна активная загрузка.
- Отдельные аудио- и видеодорожки объединяются в MP4 без перекодирования через Mediabunny.
- Прогресс, отмена, повтор при временных сетевых ошибках и проверка целостности потоков.
- Мини-окно справа снизу на обычных сайтах показывает все загрузки и результат **«Скачано»**.
- Закрытие окна синхронизируется между вкладками. Через 3 секунды после завершения последней загрузки оно автоматически скрывается; новая загрузка может показать его снова.
- В Firefox обработка выполняется в скрытой фоновой странице; в Chromium — в скрытом offscreen-документе. Дополнительная вкладка расширения не открывается.

## Постоянная установка в Firefox

Требуется **Firefox 142 или новее**. Обычный Firefox принимает для постоянной установки только расширения с подписью Mozilla, в том числе скачанные с GitHub. Подпись не требует размещения расширения в каталоге дополнений: доступна самостоятельная публикация (unlisted).

**Версия 0.1.7 подписана Mozilla и доступна для постоянной установки в обычный Firefox.**

1. Скачайте [подписанный XPI 0.1.7](https://github.com/r4mdevelopment/youtube-firefox-extension/releases/download/v0.1.7/youtube-mp4-downloader-firefox-0.1.7.xpi).
2. Откройте `about:addons`, нажмите кнопку с шестерёнкой и выберите **«Установить дополнение из файла…»**.
3. Выберите XPI и подтвердите установку. Расширение сохранится после перезапуска браузера.
4. Обновите открытые страницы. Для обновления расширения установите подписанный XPI новой версии тем же способом; активные загрузки перед обновлением завершите.

Если раньше использовали временную установку, завершите загрузки, удалите временное дополнение в `about:debugging`, затем установите подписанный XPI.

### Без подписи: Developer Edition или Nightly

Этот способ требует отдельной версии Firefox Developer Edition или Nightly. В обычном Firefox отключение проверки подписи не позволяет постоянно установить неподписанное расширение.

1. В Developer Edition или Nightly откройте `about:config` и установите `xpinstall.signatures.required` в `false`. Это отключает проверку подписи для устанавливаемых дополнений в данном профиле.
2. Скачайте Firefox ZIP из Releases и измените расширение файла с `.zip` на `.xpi`, не распаковывая его. Убедитесь, что Windows показывает расширения файлов.
3. Установите XPI через `about:addons` → шестерёнка → **«Установить дополнение из файла…»**.
4. Перезапустите браузер: расширение останется установленным.

Требования к подписи: [документация Mozilla](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/).

## Как скачать видео

1. Откройте обычную страницу `https://www.youtube.com/watch?v=...` и запустите воспроизведение.
2. Нажмите **«Скачать»** слева от лайков и выберите качество. Можно также использовать значок расширения на панели браузера.
3. Следите за прогрессом в мини-окне. Оно работает на обычных HTTP/HTTPS-сайтах; служебные страницы браузера и некоторые защищённые страницы не допускают такой интерфейс.
4. После объединения выберите место сохранения, если браузер откроет диалог. Отметка **«Скачано»** появляется после завершения сохранения файла.

Для параллельной загрузки откройте другой ролик **в новой вкладке**, запустите его и повторите эти шаги. Пятую загрузку можно начать после завершения одной из четырёх; очереди пока нет.

Кнопка **«−»** сворачивает мини-окно, **«×»** в заголовке закрывает его на всех вкладках без отмены загрузок. Для остановки конкретного задания нажмите **«Отменить»**. Firefox должен оставаться запущенным до завершения загрузок.

## Разрешения и данные

Доступ к YouTube нужен для чтения форматов и текущей сессии воспроизведения, к `googlevideo.com` — для загрузки потоков. Разрешения загрузок и локального хранилища используются для сохранения файлов и состояния заданий.

Доступ к обычным HTTP/HTTPS-сайтам нужен для показа мини-окна. Его скрипт не отправляет содержимое посещённых страниц. Данные сессии воспроизведения находятся в памяти и не записываются в историю заданий. Расширение не использует native messaging; исполняемые зависимости включены в сборку локально.

## Ограничения

- Это экспериментальная версия. YouTube может отклонить сессию или потребовать дополнительное подтверждение во время загрузки; в таком случае неполный MP4 не сохраняется.
- Поддерживаются прямые HTTPS-потоки и совместимые SABR-дорожки с фактической сессией плеера. Расшифровка подписей, преобразование `n`, защищённые видео и прямые трансляции не поддерживаются.
- Дорожки пока полностью хранятся в памяти. Несколько длинных видео могут потребовать значительный объём RAM.
- Полная проверка длинных видео, всех разрешений и потребления памяти ещё не завершена.

## Chromium

Скачайте и распакуйте `youtube-mp4-downloader-chromium-0.1.8.zip` из Releases. В `chrome://extensions` или `edge://extensions` включите режим разработчика и выберите **«Загрузить распакованное расширение»**.

Chromium-сборка использует Manifest V3 и Offscreen API (Chromium 116 или новее). Загрузка и объединение продолжаются в скрытом документе после закрытия меню расширения. Браузер нужно оставить запущенным до завершения сохранения.

В Brave 1.97.56 (Chromium 155) на локальных медиафайлах проверены кнопка и меню качеств, сохранение и независимое декодирование MP4, работа при закрытом меню, мини-окно на обычном сайте, автоматическое скрытие, четыре параллельных задания с отдельной отменой и восстановление после принудительного перезапуска фонового обработчика. Короткий реальный ролик YouTube скачан со штатной сессией плеера без дополнительной вкладки. На десятиминутном ролике 1080p в изолированном профиле YouTube потребовал дополнительную проверку плеера (`SABR_ATTESTATION_REQUIRED`); этот сценарий не подтверждён, неполный файл не сохранён. Полная проверка всех качеств и длинных видео ещё не завершена. Firefox использует постоянную фоновую страницу Manifest V2.

## Разработка

Требуется Node.js 24 или новее. Для имеющегося инструментария генерации и декодирования браузерных тестовых файлов используется Windows.

```powershell
npm ci
npm test
npm run build:firefox
npm run build:chromium
npm run lint:firefox
```

Сборки появляются в `dist/firefox` и `dist/chromium`. FFmpeg — только зависимость разработки для локально сгенерированных тестовых файлов, он не входит в расширение.

GitHub Actions проверяет тесты, обе сборки и Firefox lint. Проверка Brave запускается командой `node tests/browser/brave-offscreen.mjs`; для реального короткого ролика задайте переменную `LIVE_PROBE=1`. Эти проверки используют отдельный тестовый профиль и установленный Brave на Windows.

Браузерные проверки Firefox запускаются отдельно в изолированных профилях. Для них нужны Python 3, Firefox и `marionette_driver`, установленный в `.superpowers/browser-libs`. Запуск из корня проекта: `python tests/browser/firefox-smoke.py`, `python tests/browser/firefox-no-tab.py` и `python tests/browser/firefox-site-ui.py`. Они используют тестовую временную установку; результаты и профили сохраняются в игнорируемой папке `.superpowers/`. Проверки с локальными файлами не заменяют проверку реальной загрузки YouTube.

Четыре параллельных задания, отдельная отмена и сохранение MP4 проверены локальными медиафайлами; сохранённые файлы независимо декодированы. Короткий публичный ролик также скачан через фактическую сессию YouTube.
